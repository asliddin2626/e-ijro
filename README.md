# e-ijro tizimi

Topshiriqlar boshqaruv tizimi

### Funksiyalar:
- Admin: foydalanuvchilarni boshqarish (qo‘shish, tahrirlash, o‘chirish, parol reset)
- Viloyat bo‘limi: topshiriq yaratish
- Tuman bo‘limi: javob berish (fayl biriktirish)
- Javoblar ko‘rish, qabul/rad etish
- Fayllar yuklab olish

### Ishga tushirish:
- backend: npm run dev
- frontend: npm run build
